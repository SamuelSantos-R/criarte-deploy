# Regras para o Claude neste repositório

## Commits
- **Mudanças num convite não pedem commit.** Convites vão para o ar pelo próprio
  `criarte-deploy` / Criarte Studio, não pelo git. Não sugira nem pergunte sobre
  commit depois de editar um convite, a menos que o usuário peça.
- Sugira commit só para mudanças na ferramenta: o CLI (`cli.mjs`, `src/`,
  `templates/`) e o Criarte Studio (`app/`).

## Contexto
- Arquitetura e fluxo: `AI_CONTEXT.md`, `DEPLOY_FLOW.md`, `app/PRODUCT.md`.
